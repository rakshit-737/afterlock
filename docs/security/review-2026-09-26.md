# Security review starter (2026-09-26)

Scope: a pattern-based pass over `packages/`, `services/`, `labs/`, `scripts/`, `tests/`,
and CI workflows. This is the **starter** for design phase 9 (adversarial review), not
the review itself: it greps for known-risky constructs and reads the API trust boundary.
It does not cover semantic engine correctness, fuzzing, or dynamic testing.

Line numbers refer to the tree after the fixes below.

## Patterns searched

| Pattern | Result |
|---|---|
| `subprocess` with `shell=True`, `os.system` | None. `labs/supervisor/lab.py:60`, `scripts/doctor:19`, `tests/conformance/test_live_kind.py:26` use fixed argument vectors. |
| `yaml.load`, `pickle`, `eval(`, `exec(` | None in code. JSON-only parsing, consistent with SECURITY.md. |
| SQL / string-built queries | None: no database layer exists (API storage is in-memory). |
| Token logging | None found. API compares SHA-256 digests (`services/api/afterlock_api/app.py:112-116`); lab tokens stay in memory, pass to the canary on stdin (`labs/supervisor/lab.py:140-151`). |
| Open redirects / `RedirectResponse` | None. |
| TLS verification disabled | None. Lab client pins the kind CA from kubeconfig and checks its digest (`labs/supervisor/lab.py:105-110`). |
| Path traversal in profile loading | `packages/afterlock/evidence.py:82` restricts ids to `[a-z0-9.\-]{1,64}` (no separators); OK. |
| Endpoints without auth | Only `GET /v1/health` (`app.py:131-133`) and FastAPI docs `/v1/docs`, `/v1/openapi.json` (`app.py:99`). All data endpoints depend on `principal`. |

## Findings

| # | Severity | Location | Finding | Status |
|---|---|---|---|---|
| 1 | Low | `services/api/afterlock_api/app.py:179` | `assert body.mode in MODES` as a validation guard is removed under `python -O`. Pydantic's `Literal` already constrains the value, so not exploitable today. | **Fixed** (explicit 422). |
| 2 | Low | `services/api/afterlock_api/app.py:206-215` | `make_plan` did not catch `ModelError` from `parse_analysis_input`, so a stored case that fails model validation produced HTTP 500 instead of 422 `invalid_input` (inconsistent with `run_analysis`). | **Fixed**. |
| 3 | Medium | `services/api/afterlock_api/app.py:101-106` | Body size limit only checks `Content-Length`. A chunked request with no `Content-Length` is not bounded by `MAX_BODY_BYTES` (Pydantic `max_length` bounds only list fields; `inventory`/`case` dicts are unbounded). Memory DoS by any authenticated caller, or by unauthenticated callers if body parsing happens before the auth dependency. | Open. Enforce the limit on the streamed body (ASGI receive wrapper) or at the reverse proxy; add a test with a chunked body. |
| 4 | Medium | `services/api/afterlock_api/app.py:88-93`, `149-152`, `182-183` | In-memory `Store` has no quota: cases and analyses grow without bound per process. Analysts can exhaust memory. | Open. Per-principal quotas or eviction before any shared deployment. |
| 5 | Low | `services/api/afterlock_api/app.py:196-205` | `/verification` runs `reference.explore` up to 50 000 states synchronously in a worker thread per request; no rate limit. CPU DoS by analysts. | Open. Rate-limit or move to a bounded job queue. |
| 6 | Low | `services/api/afterlock_api/app.py:99` | OpenAPI schema and Swagger UI are served unauthenticated. Reveals the API surface only (no data). | Open / accept; disable `docs_url` in production config. |
| 7 | Low | `services/api/afterlock_api/app.py:113-116` | Token lookup iterates all known digests; timing reveals nothing about token contents (digest compare is constant-time), only the number of configured tokens. | Accept. |
| 8 | Low | `labs/supervisor/lab.py:62` | `LabError` includes the first 400 bytes of subprocess stderr. For `kubectl apply -f -` of Secret manifests, a kubectl error could echo manifest content (synthetic lab credentials) into the error printed at `lab.py:330` and CI logs. | Open. Redact stderr for commands that receive credential material on stdin. |
| 9 | Medium | `services/api/Dockerfile:9` | Image build installs `.[api]` and `uvicorn==0.30.6` with pip, resolving transitive dependencies at build time, not from `uv.lock`, and without hashes. | Open (see docs/security/supply-chain.md). |
| 10 | Info | `.github/workflows/live-lab.yml:30-40` | kind/kubectl checksums are fetched from the same origin as the binaries; protects against corruption, not upstream compromise. | Accept for now; consider committing expected checksums. |
| 11 | Info | repository | With `core.autocrlf=true` on Windows, replay fixtures are checked out with CRLF and bundle checksums fail (`BundleError: inventory.json: checksum mismatch`). Not a vulnerability, but the integrity check is working as designed and the test suite is unusable on such checkouts. | Open. Add `.gitattributes` (`datasets/** -text` or `eol=lf`). |
